# DevOps Task Manager

A hands-on DevOps learning project. This repository is the foundation for
building, shipping, and operating a simple Task Manager application
through the complete DevOps lifecycle.

## Philosophy

Learn DevOps by doing. One practical step at a time.
Every phase produces verified, working output.

## Architecture (Target)

Internet -> Nginx -> React -> FastAPI -> PostgreSQL

## Tech Stack (Planned)

- Frontend: React
- Backend: FastAPI (Python)
- Database: PostgreSQL
- Container: Docker, Docker Compose
- Reverse Proxy: Nginx
- CI/CD: GitHub Actions
- Cloud: AWS (Free Tier)
- IaC: Terraform
- Config Mgmt: Ansible
- Orchestration: Kubernetes
- Packaging: Helm
- GitOps: Argo CD
- Monitoring: Prometheus + Grafana
- Logging: Loki
- Tracing: OpenTelemetry
